# SerMil Control: обновления

Подписанный каталог для Sermil Update Manager.

Адрес каталога: https://raw.githubusercontent.com/sermilsoftware/sermil-updates/main/catalog.json

Пакеты: https://github.com/sermilsoftware/sermil-control/releases/tag/v0.99.44

Выпуск: ядро 0.99.44, Home Assistant 1.56.1, Wiren Board 1.30.5, WLED 1.2.0. Для модулей этого каталога сначала требуется ядро 0.99.44. ZIP ядра является пакетом обновления для существующей программы.

## Подключение

1. Сохраните резервную копию portable-папки программы.
2. Проверьте отпечатки открытых ключей по независимому доверенному источнику перед импортом. Файлы catalog-public.json и packages-public.json содержат только открытые ключи.
3. Импортируйте открытые ключи через «Настройки дома → Обновления → Дополнительно → Доверенные ключи» (версия 0.99.44), затем используйте «Справка → Проверить обновления» либо «Настройки дома → Обновления».
4. Программа проверяет подписи каталога и пакетов, SHA-256, версии и совместимость.

Отпечатки SHA-256:

- Каталог: `a921dcb5ebcb78d18b5f07c0d44748f72a85eccfa04e17f8224b366c67e6793d`
- Пакеты: `b1594ed5668e91206a86a1aeae7b506b943fe8ba34a7a22a547d6625e9549d5e`

Каталог sequence=2 действителен до 23 ноября 2026, 05:24:50 UTC (23 ноября, 12:24:50 по Красноярску). После истечения требуется новый подписанный каталог с большим sequence. Проверку срока и подписи отключать не следует.

Публичный репозиторий содержит каталог, открытые ключи и инструкцию. Закрытые ключи и пользовательские настройки сюда не входят.
